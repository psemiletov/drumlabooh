NEWS

October 08 2026 — Drumlabooh 13.0.0

Every release of Drumlabooh aims to be interesting and useful. The new version includes a big drumkit called Diskach (a word used in the USSR and post-Soviet countries in the 1990s to refer to a disco), with samples evoking nostalgia for the nineties. 7 instruments with 128 sample variations each!

This drumkit uses features of the new version of the Drumlabooh drumkit format - 1.1 (see the specification here: https://github.com/psemiletov/drum_sklad), where a directory can be specified as a file list, and the sample order can be reversed with a separate parameter.

This is the main engine innovation. The following changes have also taken place in the engine.

It's no secret that Drumlabooh does not support SFZ drumkits where a "horizontal" layer architecture is implied. On the other hand, Drumlabooh supports "vertical" velocity layers, so Drumlabooh is perfectly compatible, for example, with AVL drumkits. Previously, if Drumlabooh tried to load drumkits with a different architecture, the plugin crashed and brought down the DAW. Now Drumlabooh simply does not load such a drumkit, scanning it for unsupported opcodes.

As for Hydrogen drumkit support, as far as I know, Drumlabooh loads all of them except Audiophob, in which one WAV file is a renamed AIFF, and this causes a crash at the JUCE level that cannot be bypassed, so I simply blocked Audiophob from loading.

About reading samples. Inside Drumlabooh, sounds are stored in mono. It is simpler to mix this way. Stereo samples are converted to mono at input. And then, at the level of the built-in Drumlabooh mixer or DAW, you pan them. So, the Drumlabooh engine has returned to reading only the left channel from a stereo file. Previously, both channels were read and mixed into mono, with 50% volume for each channel. To simplify the code, I returned to how it was originally.

By version 13, many native Drumlabooh drumkits have been thoroughly edited - unnecessary silence or overly quiet tails were trimmed, manual fades were applied to sharp signal cutoffs, and some kit cover artwork was remade. The sound of all drumkits remains the same, do not worry about existing mixes! The changes affected only the length of some samples and non-zero fades that caused a click at the end.

In total, since 2023, Drumlabooh has accumulated a decent set of drumkits for all occasions and all times — I say "times" for a reason, because Drumlabooh comes bundled with samples of many legendary or rare hardware drum machines of past decades. And so we have:

Diskach, Avangard, Sopromat - universal large (but fast) drumkits with hundreds of samples on board; perhaps this is currently the core of Drumlabooh drumkits.

Sixties Basic, Sixties Rock, JazzKit - "live" multi-layered drumkits tailored for jazz and rock music in the genres stated in the drumkit names.

The remaining drumkits are sample sets either from old legendary drum machines - LEL, Cheetah SpecDrum, Klone Dual, or small experimental kits - Tamil, wooden, etc.
