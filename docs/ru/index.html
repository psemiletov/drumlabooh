Драмлабух

Бесплатная LV2/VSTi драм-машина для Linux and Windows

Главная Новости Скачать Руководство Донат Github

В комплекте с Drumlabooh идет несколько десятков драмкитов, подходящих под разные стили музыки от psytrance и darkwave до психоделического рока. Оригинальные киты - сэмплерные и синтезаторные, а также драмкиты, основанные на легендарных ударных установках и драм-машинах. Вот как звучат некоторые из них.

Jazzkit (джазовый кит)

Sixties Basic (для рока)

Diskach (для всего)

OM Kit (для Goa trance)

RITM (для electro)

Sopromat (для всего)

Avangard (авангард)

Возможности

  • Инфа по совместимости с DAW
  • Формат плагинов: Linux LV2/VST3, Windows VST3
  • Поддерживаемые форматы драмкитов: Drumlabooh, Hydrogen, SFZ, обычные папки с сэмплами
  • Драмлабух поставляется с десятками драмкитов - оригинальными (сэмплы и синтез) и созданными на основе сэмплов легендарных акустических ударных и драм-машин. Звук для любого жанра - от darkwave и psytrance до джаза и рока.
  • Стереовывод (со встроенным микшером), либо 36 отдельных выходных каналов, каждый из которых идет на отдельную дорожку в DAW.
  • Встроенный микшер с регуляторами панорамы, громкости, заглушения, и выбором режима панорамы
  • Эффекты для каждого инструмента: фильтры низких и высоких частот, кноб Analog обеспечит тот самый тёплый ламповый звук, а регулятор Live оживит таже самые простые ван-шоты. Функция Live работает только при включенных фильтрах!
  • Сэмплерно/синтезаторный движок на 36 инструментов с поддержкой 128 слоев/вариантов в каждом
  • Режимы воспроизведения слоев: MIDI velocity, Round Robin, Random Order
  • Умный движок случайных чисел обеспечивает уникальную для песни, но управляемую и постоянную при каждом воспроизведении цепочку значений. Имитация живого звучания конкретной партии всегда будет присуща только ей и будет постоянной каждый раз, пока вы сами не измените параметры.
  • Автоматическое заглушение открытого хай-хета при игре закрытого
  • Определенные в ките (или пользователем) группы заглушения
  • Отображение картинки драмкита, если она включена в состав
  • Удобный и простой MIDI mapping
  • Плагин написан на C++ с использованием тулкита JUCE
